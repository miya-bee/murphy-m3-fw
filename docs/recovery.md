# Recovery plan

The recovery procedure is unknown until the exact device is identified.

## Recovery requirements before first flash

- A verified factory image or complete flash dump
- A documented connection method
- A known-good cable and power source
- A way to observe boot logs
- A way to enter the vendor bootloader or recovery mode
- A checksum for every image used
- A stop condition and recovery owner

No device write should occur until these requirements are satisfied.
