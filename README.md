# Murphy M3 Firmware

Murphy M3 e-paper reader firmware development workspace.

The device is expected to arrive in December 2026. Until the device arrives, this repository contains preparation documents only. The delivered hardware revision and factory firmware are authoritative; public reverse-engineering material is reference information and must not be treated as proof of compatibility.

## Current status

- Phase 00: arrival preparation in progress
- Device: not yet received
- Factory firmware: not yet acquired
- Device flashing: not authorized

## Safety boundary

Do not flash any image until the exact hardware, factory backup, image format, and recovery path have been verified.
